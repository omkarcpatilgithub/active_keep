# ⚡ Quick Start Guide

## 30-Second Setup

1. **Download Python** (if you don't have it)
   - Go to: https://www.python.org/downloads/
   - Install it (check "Add Python to PATH")

2. **Double-click this file**:
   ```
   run_advanced.bat
   ```
   
3. **Click the green "▶ START" button**

4. ✅ **Done!** Your Teams status is now "Available"

---

## What Happens Next?

- App keeps your system active every 60 seconds
- Teams shows you as "Available" continuously
- You can work normally - no interference
- Click "⏹ STOP" to stop anytime

---

## Common Settings

### "Teams keeps showing me as Away"
→ Make sure the app status shows **"● ACTIVE"** (green)

### "I want less battery drain"
→ Increase interval to 120 seconds

### "I want even more activity"
→ Set interval to 30 seconds and select "Both" activity type
